# EGY PRICE — Web App

لوحة أسعار مبنية على تصميم EGY PRICE الأصلي، مع واجهة ثابتة وطبقة API داخل Cloudflare Worker. لا توجد مفاتيح API مطلوبة في النسخة الحالية.

## مصادر البيانات

- الذهب المصري: GoldPriceZ (قراءة صفحات الأسعار؛ قد يتغير شكل الصفحة أو يمنع المصدر الطلبات).
- العملات: Frankfurter daily reference rates — أسعار مرجعية يومية وليست أسعار بيع/شراء البنوك.
- الأسهم العالمية: Yahoo Finance chart endpoint — بيانات متأخرة/غير مضمونة كخدمة رسمية.
- البيتكوين: CoinGecko Public API — خاضع لحدود الاستخدام.
- الأسهم المصرية: TradingView scanner على سوق Egypt — مصدر غير رسمي ومتأخر؛ إذا لم يرجع رموزًا فلن نعرض أسعارًا قديمة/تجريبية بدلًا منها.

كل بطاقة تبدأ بشرطة (--) حتى وصول أول قراءة حقيقية. يتم تحديث البيانات كل 90 ثانية، مع زر تحديث يدوي. حركة الواجهة والوميض بين التحديثات بصرية فقط ولا تغيّر الرقم المعروض.

## النشر المجاني على Cloudflare

1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد كما هي.
2. افتح Cloudflare Dashboard ثم Workers & Pages وأنشئ Worker من المستودع، أو ثبّت Wrangler على جهازك.
3. من الطرفية داخل المجلد نفّذ:

```bash
npm install -g wrangler
npx wrangler login
npx wrangler deploy
```

4. افتح رابط `*.workers.dev` الذي يظهر بعد النشر.

## اختبار محلي

```bash
npx wrangler dev
```

- `/api/health` فحص الخدمة.
- `/api/market` بيانات السوق.

## ملاحظات الدقة

- تحديث الواجهة كل 90 ثانية لا يعني أن كل مصدر يحدّث بياناته كل 90 ثانية؛ لكل مزود دورة تحديث وحدود مختلفة.
- سعر الصرف من Frankfurter مرجعي ويُحدّث في أيام العمل، وليس تسعيرًا لحظيًا لسوق الصرافة.
- أسعار الأسهم قد تكون متأخرة، وقد لا تتوفر بعض الرموز خارج جلسة التداول.
- لا توجد بيانات مصطنعة كبديل عند تعطل المصدر. القسم غير المتاح يظل `--`، وتظهر حالة المصدر في شريط الحالة.
- البيانات للمتابعة المعلوماتية فقط وليست توصية مالية. راجع المصدر الرسمي قبل الاعتماد على أي رقم.
